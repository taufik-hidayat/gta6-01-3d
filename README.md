**Teluk Bayu 3D** — a complete open-world crime game in the spirit of GTA 6, built with Three.js (vendored locally, no network at run time). Explore a living grid city on foot and by car, steal cars, dodge traffic and pedestrians, outrun police cruisers under a five-star wanted system, and run a three-job story for Mira and Bang Darto worth $2,875 — a package run, a city-wide raid escape, and one last vault heist. Full HUD with minimap, day-night cycle, WebAudio synth sound, and save/load.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Controls: WASD/arrows to move and drive, E to enter/exit cars and interact, F to punch, mouse click to shoot, Shift to run/handbrake, drag the mouse to orbit the camera, P to pause, M to mute.
